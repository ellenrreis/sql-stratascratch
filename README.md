# SQL Practice: StrataScratch

Resoluções comentadas de questões de SQL da plataforma [StrataScratch](https://www.stratascratch.com/), focadas em preparação para entrevistas de dados e analytics.

## Sobre
Este repositório reúne as soluções que escrevi enquanto estudo SQL, junto com o raciocínio por trás de cada uma.

- **Dialeto:** PostgreSQL
- **Foco:** [agregações, joins, CTEs, window functions, manipulação de datas e strings]
- **Objetivo:** [ex.: me preparar para vagas de Analista de Dados / Analytics Engineer]
- **Última atualização:** [mês/ano]

## Estrutura

```
sql-stratascratch/
├── 01-easy/
├── 02-medium/
├── 03-hard/
```

Cada arquivo `.sql` segue o mesmo cabeçalho: nome da questão, link, dificuldade, tema, abordagem considerada.

## Padrões adotados

- Palavras-chave SQL em maiúsculas
- Uma CTE por etapa lógica, com nomes descritivos
- Aliases claros (sem `a`, `b`, `t1`)
- Comentário de abordagem no topo de cada arquivo

## Aviso

Os enunciados e datasets das questões pertencem ao StrataScratch. Este repositório contém apenas minhas soluções e anotações pessoais, com link para a questão original.
